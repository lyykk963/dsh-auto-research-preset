# PPT 工作流契约（中文科研场景）— v9.2

> 来源：融合研究 `references/ppt-style-library.md`（真身位于 `%USERPROFILE%\.trae-cn\skills\融合研究\references\`）。
> 本契约只迁**可用的判定与素材**（场景表 / 字体表 / 布局模式 / 默认推荐 / 四步流程），
> **不迁**其 §1 数量声明、§7 路径映射、§8 生成脚本（理由见文末「已弃用」）。
> 定位：把「PPT 场景 → 风格 → 字体 → 布局」从凭感觉决定变成**先问后做**的固定流程，
> 并解决本预设此前的一个真实空白——DSH 侧 16 个模板全是英文设计模板，**无任何中文答辩/国自然/职称场景映射**。

## 1. 强制前置：四步询问（不得跳过直接生成）

任何 PPT 需求，生成前必须先走完四步并得到用户选择。与融合研究「原则 0：先问再做」「原则 3：作图必问」同源。

```
Step 1 场景 → Step 2 配色 → Step 3 字体 → Step 4 页数/时长与布局 → 然后才生成
```

**Step 1 · 场景**（原文逐字）

```
您需要制作什么类型的 PPT？
1. 📄 论文答辩（学位论文/开题/预答辩）
2. 🏆 人才申报/职称评审（长江学者/教授/副教授等）
3. 🔬 国家自然科学基金申报（申请/结题汇报）
4. 📊 科研报告（项目进展/重点研发计划）
5. 📚 文献汇报/组会
6. 📋 通用汇报（工作汇报/产品介绍）
7. 🎨 自定义（提供您的模板或描述）
```

**Step 2 · 配色**：按 Step 1 列出该场景可选配色（见 §3），并给「自定义主色/强调色」出口。

**Step 3 · 字体**（原文逐字）

```
1. 微软雅黑 + Times New Roman（经典推荐）
2. 微软雅黑 + Arial（现代感）
3. 方正尚酷简体 + Century Gothic（科技感）
4. 保持原模板字体
```

**Step 4 · 页数/时长与布局**

```
预期演讲时长：___ 分钟
→ 建议页数：约 ___-___ 页（参考 1 页/分钟）
布局偏好：
1. 顶部色块式（最通用）  2. 左侧导航式（适合文献汇报）
3. 校徽封面式（学校答辩）4. 跟随所选模板默认布局
```

**Step 5 · 图规划（v9.4 新增，强制）**：逐页填 `contracts/slide-design.md` §2 的图规划表（标题写结论句 / 视觉类型 / 来源）。
填不出视觉类型的页，要么与相邻页合并，要么改成图。产出后用 `tools/check_deck.py` 体检：
纯文字页 >50% 或 图形对象不足 → **不得交付**。

## 6. 与本预设 PPTD 管线的分工（避免双管线）

本预设已有的 PPTD 管线是**执行层**，本契约是其**决策层**：

```
Step 1–4 询问（本契约）
   → 选定模板（§2 索引）或选定 DSH 设计模板（ppt_list_templates，16 个 dsh-* 英文设计模板）
   → pptd_import 把选定 .pptx 转成可编辑 PPTD 工程
   → 编辑 .pptd/.page（pptd_read_file / pptd_write_file）
   → pptd_check 校验 → pptd_render 导出 PPTX + 浏览器交付
```

**铁律**：不要另起一条生成链路（例如直接调用外部 pptx 脚本）。DSH 的 PPTD 管线是唯一渲染出口——它自带路径、资源、格式与编译保护。

**中文科研场景无现成模板时**（如论文答辩 0 套）：明确告知用户，给出两条路——① 用户提供模板（走 `pptd_import`）；② 用最接近的 DSH 设计模板（`dsh-engineering-blueprint` / `dsh-editorial-notebook` / `dsh-monochrome` 等）承载内容。**不得假装有模板。**
