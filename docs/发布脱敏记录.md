# 发布脱敏记录

本仓库源自一份私人开发副本。为了让它可以公开，发布前做了以下删改。**功能逻辑未改**，只删内容/换占位。

## 1. 个人绝对路径 → 占位或环境变量

| 原内容 | 现在 |
|---|---|
| `C:\Users\<用户名>\...` | `%USERPROFILE%\...` |
| `D:\harness\...`（私人工作区） | `<workspace>`；工具里改为 `SCI_WORKSPACE` 或 `os.getcwd()` |
| 预设安装路径写死 | `%APPDATA%\dsh-desktop\harness\.agent-presets\auto-research` |
| `agent.cordis.yml` 里写死 Trae 技能目录的 `file:///C:/Users/...` | `process.env.TRAE_SKILLS_DIR \|\| ~/.trae-cn/skills`（缺失不报错） |
| `C:\Users\<用户名>\Desktop\templates_cache` | `%USERPROFILE%\Desktop\templates_cache` |

涉及文件：`preset/agent.cordis.yml`、`preset/skills/auto-research/SKILL.md`、`.../references/artifact-contracts.md`、
`.../contracts/*.md`、`.../assets/ppt-templates.index.json`、`.../tools/{audit_preset_assets,cost_metrics,fetch,review_metrics,selfcheck,skill_routing,verify_v9_upgrade}.py`，以及 `portable/` 下的同名镜像。

## 2. 论文专属红牌规则 → 只留通用引擎

原 `tools/advisor_pattern_gate.py` 的 `BUILTIN_PROFILE` 与 `gates/<论文>-pattern_profile.json` 里含**某一篇未发表论文**的专属规则
（具体禁用词、层数/通道数口径、seed 数口径、失效 p 值、被推翻的旧叙事短语、论文/稿件编号）。公开发布版：

- 删除 3 条论文专属 `banned_terms`（`B-FAIR` / `B-DECOUPLED` / `B-PROOF-BY-RETENTION`）；
- `numeric_invariants` 与 `narrative.{forbidden_phrases,canonical_claims}` 清空（结构保留，供 `--profile` 注入）；
- 删除原论文的专属 profile 文件（`<论文>-pattern_profile.json`）；
- `gates/paper_redline_profile.template.json` 重写为**中性示例模板**（示例规则 + 键说明）；
- 保留的通用规则：em dash、TOST 与 non-inferiority 冲突、不可证卖点词（privacy-friendly / 超范围 gradient-free）、
  单次运行当结论、句长/caption/小节阈值、填充语、拼写混用、合规包装、残留占位符，以及 8 条 v1.3 通用规则。

配套自测（`--self-test`）的正/负控制样例文本也换成了通用论文语料，控制项 18/18 通过。

## 6. 恢复私人规则

公开版保留完整引擎。要恢复你自己的论文规则：

1. 复制 `preset/skills/auto-research/gates/paper_redline_profile.template.json` 成 `my-paper-profile.json`（该文件名已在 `.gitignore` 中）；
2. 按模板填入你的禁用词 / 口径规则 / 叙事短语；
3. 运行：`python tools/advisor_pattern_gate.py <稿件...> --profile my-paper-profile.json --strict`。
